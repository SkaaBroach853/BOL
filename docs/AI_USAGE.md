# AI and third-party resource disclosure

OpenAI Codex was used to read the supplied handoff, implement application code and tests, diagnose installation/browser issues, inspect actual screenshots, and prepare documentation. No human user interviews, external user studies, invented commit history or performance claims are presented. No sub-agents were used.

The supplied `BOL_CODEX_MASTER_HANDOFF.md` is the product specification. The project started with that document only; there was no pre-existing application implementation or dataset. The Sites skill guided local-only development and interface review. The OpenAI Docs skill and official sources guided the real provider adapter. Initial development performed no Site registration, cloud deployment, repository publication, messages or submission. The owner subsequently authorized uploading this project to GitHub.

Third-party libraries: React / React DOM (MIT), Vite (MIT), TypeScript (Apache-2.0), Express (MIT), Zod (MIT), dotenv (BSD-2-Clause), tsx (MIT), Lucide React icons (ISC), Playwright (Apache-2.0), axe-core / axe Playwright integration (MPL-2.0 / project-provided licensing). Exact dependency versions and transitive licenses are available in `package-lock.json` and installed package LICENSE files. Node's bundled SQLite binding is used; SQLite is public domain. No custom model training, image generator, stock photography or remote font service was used. Branding/favicon are simple application-native shapes and text. Fonts are supplied by the operating system, with Devanagari fallback.

Optional runtime AI: real OpenAI transcription and Responses structured interpretation, when the user supplies a server-only API key. No key was available during implementation, so no live success, recognition accuracy, provider usage or cost is claimed. Provider unit tests use explicit mock HTTP transports. Browser recording lifecycle tests use a generated browser audio stream, not a person's recorded voice. The application contains no mocked voice responses.

The rule-based typed parser is local deterministic code, disclosed in the interface. Its 26-case hand-authored evaluation is small and authored alongside implementation; it is not an independent benchmark or speech-recognition evaluation. Real browser screenshots in `docs/screenshots/` capture the running application with fictitious ledger entries generated through actual local API confirmations.
