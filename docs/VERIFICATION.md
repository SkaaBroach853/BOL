## Actual local audio evidence

Input was offline Windows system-TTS English speech saying `Suresh credit forty rupees.` This is synthetic speech, not human Hindi or a noisy-street recording. It is held under ignored data/ and never transmitted to a cloud inference service.

Observed returned transcript: **Suresh Credit 40 Rupees.** The local agents returned ADD_CREDIT / Suresh / 4000 paise. The test asserted the ledger still totaled zero after interpretation and preview. Only a separate explicit confirmation then saved INR 40 in the isolated in-memory test shop.

The last local test observation was approximately **23.2 seconds** for upload-to-preview, including worker/model cold loading while the machine was also building the app. This is one synthetic sample, not a general latency or accuracy claim. A prior cold observation was approximately 10.5 seconds. CPU load affects timing; the worker persists to avoid reloading for each recording. No percentile, human-recognition accuracy or provider cost estimate is claimed.

Exact latest observation is in `local-speech-verification.json`. There is no paid inference request, cloud credential, cloud fallback or simulated response in the running app. Package and model downloads need internet at setup; normal worker startup uses local_files_only=True and HF_HUB_OFFLINE=1. A physical external-network disconnection has not been rehearsed.

## Remaining limits

- Human Hindi/mixed-language microphone recognition, regional dialects, street noise, physical Android Chrome, actual OS permission prompts and screen readers remain unverified.
- Interpretation/review are bounded rule-based code agents, not a trained general-purpose LLM. Whisper is a pretrained open model, not a model trained from scratch by BOL.
- Local CPU inference can be slow, especially the first request. The model and isolated Python environment require a one-time download on another machine.
- Latest eligible transaction corrections only; single local shop; no auth, public deployment, bank/UPI/WhatsApp execution, PWA, offline page reload, remote sync or archive-browsing UI.
- Browser drafts and pending operation IDs stay local; authoritative writes still require the running local server. SQLite's Node 22 binding emits its experimental API warning.

No application was deployed or entry submitted. GitHub source publication was authorized by the owner. The model, Python environment, audio, ledger databases, keys and caches are excluded from Git.
